# عبد المالك استوديو — الموقع + لوحة الإدارة

موقع static بسيط (HTML / CSS / JavaScript عادي، من غير framework ولا سيرفر ولا قاعدة بيانات؛ بيشتغل مباشرة من `site/`، وخطوة بناء بسيطة `tools/build.js` بتجهّز `dist/` للنشر فقط).
الموقع العام بيتنشر على **GitHub Pages**، ولوحة الإدارة **بتفضل على جهازك بس**.

## التشغيل محليًا (من غير سيرفر)

- الموقع: افتح `site/index.html` في المتصفح مباشرة.
- لوحة الإدارة: افتح `admin/index.html` في المتصفح مباشرة.

مفيش حاجة تتثبّت. السكريبتات عادية (مش ES modules) والبيانات في ملف `.js` عشان الفتح المباشر من الملفات يشتغل.

## شكل البيانات (`site/data/data.js`)

الملف عبارة عن JSON صرف (منسّق على أسطر): `window.STUDIO_DATA = { ... };` — مفيش فيه أي كود.

- **`site`**: `name`, `nameEn`, `owner` (اسمك تحت الصورة)، `verified` (علامة التوثيق)، `tagline`, `about`, `photo`, `logo`, `accent`, `accent2`, `socials[]`
  (`photo` و`logo` مسارات نسبية من مجلد `site/`، مثلًا `assets/img/logo.svg`)
- **`sections`**: مصفوفة أقسام (حاليًا **15 قسم** و**147 عنصر**: 131 رابط، 11 Prompt، 3 فيديو، 2 ملف). كل قسم: `id`, `title`, `icon`, `desc` (سطر وصف تحت العنوان)، `cover` (صورة الغلاف — مسار نسبي من `site/` أو لينك https)، `items[]`
  - كل عنصر: `id` (معرّف ثابت وفريد، مثل `itm-1a2b3c4d`)، `type` (`link` / `prompt` / `video` / `file`)، `title`, `desc`، و`url` (أو `text` لو النوع `prompt`).
  - **`price`** (اختياري): حالة السعر `مجاني` / `مجاني محدود` / `مدفوع` (أخضر / أحمر تلقائي). البرومبتات والفيديوهات والملفات عادةً من غير سعر.
  - **`category`** (اختياري): تصنيف العنصر جوه قسمه (من تصنيفات القسم). بتتدار من لوحة الإدارة: «تصنيفات القسم» (إضافة/إعادة تسمية/حذف) واختيار التصنيف في العنصر؛ تصنيف جديد بتكتبه في العنصر بيتضاف لقايمة القسم لوحده وبيظهر في الموقع تلقائيًا. القسم نفسه ليه `categories` (قايمة مرتبة).
  - **`tag`** (قديم): لسه موجود في الملف ومتلمسش. لو العنصر ملوش `price`/`category` الموقع بيقرا `tag` (كلمة سعر ← سعر، غيرها ← تصنيف). `node tools/migrate-price-category.js` رحّل الموجود مرة واحدة.
- **`updates`** (اختياري، على مستوى الملف): ملاحظات «آخر الإضافات» `{date, title, text, items:[ids]}` — بتتدار من لوحة الإدارة.
- في `site`: `visitors: false` بيقفل عدّاد الزوار، و`reportEmail` (اختياري) إيميل بلاغات الروابط المعطلة.

**الأقسام الظاهرة:** كل الـ15 قسم ظاهرة في الموقع (وفي التابات). لو قسم بقى فاضي مستقبلاً بيختفي عن الزوار لحد ما تضيف له عناصر.

**الأدوات المميزة:** 6 عناصر موجودة فعلًا متعلّم عليها `featured: true` (Behance البورتفوليو، Claude، Google Fonts عربي، Unsplash، Photopea، Figma) — تقدر تغيّرها من اللوحة (خانة «إظهار في الأدوات المميزة»). **آخر الإضافات:** مفيش عنصر ليه تاريخ `added` لسه (مفيش مصدر موثوق للتواريخ)، فالجزء والتاب مخفيين لحد ما يبقى فيه تواريخ حقيقية؛ العناصر الجديدة من اللوحة بتاخد تاريخ يوم إضافتها تلقائيًا.

معرّف العنصر بيتولّد تلقائيًا ومبيتغيّرش مع الترتيب أو التعديل. معرّف القسم بيظهر في اللوحة ولازم يكون فريد.

## أغلفة الأقسام والتجربة

- كل قسم له بانر بعنوان كبير ووصف، وبين كل قسم والتاني خط فاصل.
- أغلفة الأقسام الـ16 (15 ظاهر + القسم الفاضي) رسومات SVG أصلية بألوان الهوية (في `site/assets/img/sections/`)، وتقدر تستبدل أي واحد بصورتك: حط الصورة في نفس المجلد، واكتب مسارها في خانة **صورة غلاف القسم** في اللوحة (مثلًا `assets/img/sections/fonts.jpg`، عرض حوالي 1600px). لو الخانة فاضية أو الصورة مش بتفتح بيظهر غلاف افتراضي.
- العنوان الرئيسي هو الاسم الإنجليزي `Abdelmalek Studio`، واسمك تحت الصورة مع علامة التوثيق (من خانتي **اسمك** و**علامة التوثيق** في اللوحة).
- حركة عند النزول، الهيدر ثابت أثناء التمرير، شريط تقدم، زر رجوع لأعلى، إشعار عند النسخ، **من غير أي صوت** (الصوت اتلغى نهائيًا — مفيش زر ولا إعدادات؛ التفاعلات بصرية والرسائل صامتة)، والحركة بتتقفل تلقائيًا لو الجهاز عامل "تقليل الحركة". اختصار `/` بيفتح البحث.

## استخدام لوحة الإدارة

1. افتح `admin/index.html`. بتتحمّل بيانات `site/data/data.js` الحالية.
2. عدّل الملف الشخصي، أو أضف / عدّل / احذف / رتّب الأقسام والعناصر (أزرار ↑ ↓).
3. دوس **تنزيل data.js**. قبل التنزيل اللوحة بتتحقق من:
   - أسماء الأقسام والعناصر مش فاضية، ونص الـ Prompt موجود في عناصر `prompt`.
   - **اللينكات** (عناصر + أزرار التواصل) بنفس القواعد ونفس رسائل الخطأ: `https://` أو `http://` بس، من غير يوزر/باسورد جوه اللينك ولا مسافات، ونطاق فيه نقطة. أي `javascript:` أو `data:` أو `vbscript:` أو `file:` بيتقال عليه «غير آمن» وبيتمنع. (أزرار التواصل بتقبل كمان `mailto:`، وعناصر الملفات بتقبل مسار `assets/...`.)
   - **صورة البروفايل واللوجو وأغلفة الأقسام**: مسار نسبي من `site/` بامتداد صورة (`jpg/png/webp/gif/svg/avif/ico`) من غير `..` ولا `/` في الأول ولا بروتوكول، أو لينك https. الخانة الفاضية مقبولة.
   - **الألوان**: كود بصيغة `#RGB` أو `#RRGGBB` (زي `#FDC713`). الخانة الفاضية معناها اللون الافتراضي.
   - معرّفات الأقسام مش مكررة، ومعرّفات العناصر فريدة.

   لو فيه خطأ، التنزيل بيتوقف وبتظهر قائمة بالأخطاء ومكان كل واحد (قسم / عنصر) مع زرار "روح للمكان".
   بعد التنزيل اللوحة بتتأكد كمان إن ملفات الصور المحلية موجودة فعلًا جوه `site/`، ولو ملف ناقص بتظهر **ملاحظة تنبيه** (من غير ما تمنع التنزيل، لأن الموقع بيعرض بديل).
4. حط `data.js` المنزّل مكان `site/data/data.js`، وافتح `site/index.html` وراجع، وبعدين ارفع على GitHub.

**إضافات اللوحة:** بحث في كل العناصر، عدّاد عناصر لكل قسم، زرار **نسخ** لأي عنصر، **فحص التكرارات** (روابط مكررة، أسماء مكررة، Prompts مكررة، عناصر متشابهة — تنبيه فقط)، **معاينة التغييرات** (إيه اللي اتضاف/اتحذف/اتعدّل قبل ما تنزّل)، محرر **آخر الإضافات والتحديثات**، وتحذير قبل أي استيراد هيخفي عناصر. فحص الصور بيفرّق بين «مش موجودة» و«ما اتأكدناش منها (انتهت المهلة)».

### النسخ الاحتياطي والاسترجاع
- **نسخة احتياطية**: بتنزّل ملف `abdelmalek-backup-التاريخ.json` فيه كل البيانات (بدون أي سيرفر). بتشتغل حتى لو لسه فيه أخطاء، عشان تحفظ شغلك.
- **استرجاع نسخة**: اختار ملف `.json` (أو `data.js`). اللوحة بتعرض عدد الأقسام والعناصر اللي فيه وبتسألك قبل ما تستبدل البيانات الحالية. لو رفضت، مفيش حاجة بتتغيّر. نفس السؤال بيظهر عند **فتح data.js**.
- **رجوع للأصل**: بيرجّع البيانات الموجودة حاليًا في `site/data/data.js` (بعد تأكيد).

لو الملف المستورَد فيه بيانات غير صحيحة (لينك غير آمن، لون غلط...) بيتحمّل برضه من غير فقدان أي حاجة، وبتظهر قائمة الأخطاء ومكانها، والتنزيل بيفضل ممنوع لحد ما تتصلح.

الملفات بتتقرا كبيانات JSON بس، ومفيش أي كود بيتنفّذ منها. الصيغة القديمة (`const SITE = ...; const SECTIONS = ...;`) لسه بتتفتح وتتحوّل تلقائيًا.

## الوضع الفاتح/الغامق والفلاتر والمفضلة والمميزة

- **الوضع الفاتح/الغامق**: زرار في الهيدر. الاختيار بيتحفظ في المتصفح، والافتراضي غامق. بانرات الأقسام بتفضل غامقة في الوضعين عشان الأغلفة.
- **الفلاتر والبحث (لكل قسم)**: مفيش فلاتر عامة. لما تفتح قسم بيظهر تحت الشريط:
  - **التصنيف**: تصنيفات القسم نفسه (من `categories` في القسم + التصنيفات المستخدمة في عناصره) بعدد كل تصنيف، بيظهر لما يبقى فيه تصنيفين أو أكتر. مثال Prompts: تعديل الصور، تايبوجرافي، رفع جودة الصور، إنشاء الشخصيات، المنتجات، الشعارات والهوية، تحريك اللوجو، قاموس الكلمات، مكتبات Prompts. أقسام الأدوات (فيكتور، مونتاج، موشن، أفكار، مواقع، AI صور) ليها تصنيفاتها.
  - **السعر** (الكل / مجاني / مدفوع): في أقسام المواقع والأدوات بس. «مجاني» بيشمل المجاني بالكامل والمجاني المحدود (اللي فيه جزء مجاني)، و«مدفوع» = المدفوع بالكامل. شارة السعر الصغيرة ثابتة في أعلى كل كارت (أخضر مجاني / أحمر مدفوع / أصفر مجاني محدود). كل أداة بحالتها هي، مفيش موقع بيتصنّف كله مجاني أو مدفوع.
  - **البحث** مرتبط بالقسم المفتوح (والرئيسية بتدوّر في الكل): نتايج فورية مع العدد، يدوّر في العنوان والوصف والكلمات المفتاحية والتصنيف مع المرادفات والكلمات القريبة («تايبوجرافي»، «رفع الجودة»، «كركتر»...). لو في نتايج في أقسام تانية بيظهر زرار «… في باقي الأقسام». «مسح الكل» بيرجّع كل حاجة.
- **المفضلة**: قلب صغير على كل كارت، بيتحفظ في المتصفح (`localStorage`) بمعرّف العنصر الثابت، فيفضل محفوظ لما الزائر يرجع. زرار «مفضلاتي» بيعرض المحفوظ بس.
- **مجموعات المفضلة**: جوه «مفضلاتي» تقدر تعمل مجموعات (أدوات التصميم، الذكاء الاصطناعي، المونتاج، الإنتاجية، أو أي اسم)، وتنقل أي مفضلة لمجموعة من القايمة تحت الكارت. محلية بالكامل في `localStorage` (مفتاح `as-fav-groups`) من غير حساب ولا سيرفر، ومبتلمسش قايمة المفضلة القديمة (`as-fav`). حذف مجموعة بيرجّع عناصرها «بدون مجموعة» ومبيشيلهاش من المفضلة.
- **روابط مباشرة**: كل عنصر له رابط ثابت `…/#i=<id>` (زرار المشاركة على الكارت وفي نافذة البرومبت). بيفتح الموقع على القسم ويظلّل الكارت (والبرومبت بيفتح نافذته). كمان البحث والفلاتر والقسم و«مفضلاتي» و«آخر الإضافات» كلها في الـ URL (`#s=…&t=…&p=…&c=…&q=…`) فتتشارك وزرار الرجوع بيشتغل. مفيش صفحات منفصلة، وبيشتغل على GitHub Pages وعلى `file://`.
- **آخر الإضافات**: تاب «✦ آخر الإضافات» + «عرض الكل» بتفتح صفحة بتجمع بالتاريخ العناصر اللي ليها `added` وملاحظات `updates`. بتظهر بس لما يكون فيه بيانات.
- **الإبلاغ عن رابط معطل**: علم 🚩 على كروت الروابط بيفتح رسالة جاهزة (اسم الأداة + اللينك + رابطها في الموقع) تتبعت على واتساب (من زرار واتساب في بيانات الموقع) أو إيميل (`site.reportEmail`) أو تتنسخ. مفيش سيرفر ولا بيانات بتتجمع.
- **الأدوات المميزة**: من لوحة الإدارة علّم أي عنصر بـ «إظهار في الأدوات المميزة» (بيتحفظ كـ `"featured": true` في `data.js`). بتظهر في جزء صغير بعد المقدمة وقبل التابات، وبتختفي أثناء البحث أو الفلترة أو لما تفتح قسم واحد. لو مفيش عناصر معلّمة الجزء كله مبيظهرش.
- **الإحصائيات**: أعداد الأقسام والمواقع والـ Prompts والفيديوهات والملفات بتتحسب تلقائيًا من `data.js` (الصفر بيتخفي).
- **صورة المشاركة (OG Image)**: الـ meta tags جاهزة، وصورة المعاينة معلّم عليها تعليق في `index.html` لحد ما رابط GitHub Pages النهائي يتحدد.

## البحث الذكي والاقتراحات (المرحلة 2)

- **المرادفات**: البحث بيفهم وظيفة الأداة بالعربي والإنجليزي حتى لو الكلمة مش في اسمها. مثلًا «Background Removal» أو «إزالة خلفية» بيظهروا Remove.bg وClipdrop. المرادفات في `site/assets/js/synonyms.js` (مصفوفة `SYN`)، وتقدر تضيف مجموعة جديدة بنفس الشكل. المرادفات بتدوّر في الاسم والوصف والتصنيف والكلمات المفتاحية بس (مش نص البرومبت الطويل) عشان النتايج تفضل دقيقة.
- **اقتراحات أثناء الكتابة**: أفكار ← أقسام ← أدوات، وبتشتغل بالأسهم وEnter وEsc.
- **مسح الكل**: زرار بيظهر لما يبقى فيه بحث أو فلتر أو قسم محدد، وبيرجّع كل حاجة. وفي خانة البحث زرار × لمسح الكلمة، و**Esc** بيقفل الاقتراحات وبعدها بيمسح البحث، و**Enter** من غير اختيار بينقل التركيز لأول نتيجة، وزرار «مشاركة النتائج» بينسخ رابط البحث والفلاتر. لو مفيش نتائج بتظهر اقتراحات وأقسام تتصفحها.
- **البرومبتات**: زرار **Copy** على الكارت نفسه (من غير فتح النافذة)، وتصنيفات الاستخدام بتظهر في قسم Prompts.

### حقول اختيارية جديدة في `data.js` (مش لازم تتملي)
- `keywords` (لأي عنصر): نص بفواصل أو قائمة، بتدخل في البحث. مثال: `"keywords": "إزالة خلفية، background removal"`.
- `tool` (للبرومبت): الأداة المتوافقة، بتظهر كشارة على الكارت وفي النافذة. مثال: `"Gemini / Nano Banana"`.
- `image` (للبرومبت): صورة النتيجة المتوقعة (مسار نسبي من `site/` أو لينك https)، بتظهر على الكارت وفي النافذة. لو الصورة مش بتفتح بتتشال والكارت يفضل نصي.

- `added` (لأي عنصر): تاريخ الإضافة `YYYY-MM-DD`. أحدث 6 عناصر متأرّخة بتظهر في قسم **آخر الإضافات** فوق الأقسام، والقسم بيختفي لو مفيش عناصر متأرّخة. أي عنصر جديد من لوحة الإدارة بيتأرّخ بتاريخ النهارده تلقائيًا.

**زرار المشاركة** على كارت أي أداة ليها لينك: بيفتح مشاركة الموبايل لو متاحة، وإلا بينسخ لينك الأداة. البرومبتات ليها زرار Copy بدل المشاركة.

كلها بتتعدل من لوحة الإدارة. مفيش بيانات حالية اتغيّرت، وحقل `tag` زي ما هو.

## النشر على GitHub Pages

**الهدف:** حساب `Abdelmalek-Studio` ← مستودع باسم **`Abdelmalek-Studio.github.io`** ← الموقع على **https://abdelmalek-studio.github.io/** (جذر الدومين، من غير اسم مستودع في المسار). المستودع لسه ماتعملش، والمشروع مجهّز على الاسم ده من غير ما يفترض إنه موجود.

**الخطوات (مرة واحدة):**
1. على GitHub: **New repository** باسم `Abdelmalek-Studio.github.io` (عام Public)، وارفع المشروع (فرع `main`). رفع `package-lock.json` ضروري (الـ workflow بيستخدم `npm ci`).
2. **Settings ← Pages ← Build and deployment ← Source = GitHub Actions** (متختارش "Deploy from a branch").
3. أي push على `main` بيشغّل `.github/workflows/pages.yml`: الأول job **`test`** (فحص syntax + `npm test` كاملة)، ولو نجح بس يشتغل job **`deploy`** (`needs: test`) اللي بيبني `dist/` وينشره. **فشل أي اختبار = مفيش نشر.** تقدر تشغّله يدويًا من تبويب Actions.
4. الرابط الدائم لأي عنصر: `https://abdelmalek-studio.github.io/#i=<id>`.

**إيه اللي بيتنشر:** مجلد `dist/` بس (نسخة من `site/` + `robots.txt` + `sitemap.xml` + canonical/og:url متولّدين تلقائي من اسم المستودع الحقيقي). `tools/build.js` بيفشل لو لقى أي ملف admin أو ملف مرجعي ناقص أو مسار مطلق. الاختبار `tests/production.js` بيتأكد كمان إن dist مفيهوش admin/tests/tools/أسرار.

**ملفات الإدارة (`admin/`):** مرفوعة في المستودع (مش في `.gitignore`) لأن الاختبارات (`tests/admin.js` وغيره) وGitHub Actions محتاجينها بعد الـ clone. معنى كده إن كود اللوحة **ظاهر في المستودع العام** (من غير أي بيانات سرية أو مفاتيح — اللوحة محلية ومفيهاش اتصال بأي سيرفر)، لكنها **مش بتتنشر** على الموقع ولا بتدخل `dist/`. لو عايزها على جهازك بس: فعّل سطر `admin/` في `.gitignore` (والاختبارات هتحتاجها عندك). متحطش اللوحة جوه `site/`، ومتعتمدش على `noindex` كحماية — الحماية إنها مش بتتنشر أصلًا. ملفات النسخ الاحتياطي (`abdelmalek-backup-*.json`) في `.gitignore` عشان متترفعش بالغلط.

**الإصدارات:** `package-lock.json` مرفوع، وPlaywright مثبّت على نسخة محددة (`1.63.0`) بحيث الـ CI يشتغل بنفس النسخة اللي اتجرّبت. محتاج Node 20 أو أحدث.

## الشكل (مرحلة التصميم)

كله CSS + سطور قليلة في `app.js`، **من غير أي تغيير في البيانات** (`data.js`) ولا وظائف. الطبقة كلها في `site/assets/css/studio.css` (فوق الملفات القديمة؛ لو عايز ترجع الشكل القديم شيل سطر `studio.css` من `index.html`).

- **العرض**: الموقع بيملا الشاشة كلها (بدل عمود ثابت 1100px)، والكروت بتزيد أعمدتها مع عرض الشاشة (5 أعمدة على 1920px).
- **شريط التنقل العلوي**: تحت الهيدر وروابط السوشيال مباشرة، كبير وبريميوم (خلفية داكنة، نص أبيض، كل قسم بأيقونته وعدد عناصره، والنشط بتعبئة كاملة بتدرّج الهوية البرتقالي المايل للأحمر). على الديسكتوب **كل الأقسام ظاهرة مرة واحدة** (بتنزل في أكتر من صف) من غير تمرير مخفي، وبيلزق تحت الهيدر ويصغّر شوية بعد النزول. «الكل» (الرئيسية) بأيقونة بيت. الضغط على قسم بيعرض محتواه وبس **وبينزّل الصفحة بنعومة لحد ما الشريط يبقى فوق تحت الهيدر** (الاسم والصورة يطلعوا برّه الشاشة والمحتوى تحت الشريط). على الموبايل: شبكة من صفّين بتتسحب أفقيًا (مش لازقة). الأيقونة والعدد بييجوا من بيانات القسم (`icon`) وعدد عناصره. الاسم العربي تحت الصورة بعرض الصورة بالظبط مع علامة التوثيق.
- **لون لكل قسم**: بيتحسب تلقائي من ترتيب القسم (درجة لون `--h` من `app.js`) — فلو أضفت قسم جديد من اللوحة هياخد لونه لوحده، ومفيش حاجة بتتكتب في البيانات. اللون بيظهر في البانر والأيقونة والكروت وتوهّج الخلفية، وبيتغيّر مع القسم المفتوح. رسمة غلاف القسم بتتلوّن بنفس اللون (`hue-rotate`).
- **الخلفية**: ألوان الهوية (الأصفر والبرتقالي) منتشرة جوّه الخلفية كتوهّج، مع توهّج تاني بلون القسم الحالي. ثابتة ومش بتأثر على سرعة الصفحة.
- ألوان الهوية الأساسية (`#FDC713` / `#F58220`) لسه من `data.js` (`site.accent`).

## ملاحظات

- الموقع **عربي RTL** والخط Cairo. اللون الأساسي `#FDC713` والتاني `#F58220` هوية صاحب الموقع.
- نسخ الـ Prompt: بيظهر "Copied ✓" بس لو النسخ نجح فعلًا، ولو فشل بيظهر "Copy failed ✕".
- البحث بيشمل اسم القسم واسم العنصر والوصف والتصنيف ونص الـ Prompt **واسم النطاق واللينك** (مثلًا `canva` أو `canva.com` أو لينك كامل ملصوق، وبيتجاهل `https://` و`www.`)، مع توحيد الحروف العربية (تشكيل، أ/إ/آ، ة/ه، ى/ي). نص البحث لكل عنصر بيتحسب مرة واحدة، فالبحث سريع حتى مع مئات العناصر.
- **بدائل الصور**: لو صورة البروفايل مش موجودة أو فشل تحميلها بتظهر صورة اللوجو، ولو اللوجو كمان فشل بيظهر أول حرف من الاسم. نفس الفكرة للوجو في الهيدر. الغلاف اللي مبيفتحش بيتبدّل بالغلاف الافتراضي. ألوان الهوية لو كودها غلط بيتتجاهل ويفضل اللون الافتراضي.
- **عدّاد الزوار** (`visitors.js`): **مقفول في النسخة الأولى** (`"visitors": false` في `site` داخل `data.js` — مفيش أي طلب لخدمة خارجية). لتفعيله لاحقًا: من اللوحة فعّل «إظهار عدّاد الزوار» (بيشيل الإعداد). لما يتفعّل بيستخدم خدمة CounterAPI المجانية، مبيشتغلش على `file://` ولا localhost، ولو الخدمة وقعت بيتخفي. ⚠ الخدمة ليها حد مجاني (1000 زيادة/يوم حسب صفحة أسعارها) وبتتصل بموقع خارجي، وموقعها مبيضمنش إن واجهة `v1` المجهولة المستخدمة هتفضل شغالة. لو عايز تقفله: من اللوحة شيل «إظهار عدّاد الزوار» (بيكتب `"visitors": false` في `site`).

## الـ Prompts والفيديوهات

- **كروت الـ Prompts**: بره بيظهر الاسم والشرح بس. الضغط على الكارت بيفتح نافذة فيها الاسم والشرح والـ Prompt كامل بتنسيق مقروء (JSON ملوّن أو نص بعناوين)، ومن جوه بتعمل **Copy Prompt**. الضغط على Esc أو برّه النافذة بيقفلها. النسخ بياخد النص الأصلي بالحرف.
- **فيديوهات يوتيوب**: أي عنصر نوعه `video` ولينكه يوتيوب بتظهر صورته المصغرة بره، والضغط على الكارت بيفتح الفيديو. عشان تضيف فيديو جديد: من اللوحة أضف عنصر نوع **فيديو** واكتب اللينك. لو حبيت العنوان ينزل تلقائي من يوتيوب سيب العنوان أي حاجة مؤقتة وفعّل `"autoTitle": true` في العنصر، ولو كتبت عنوانك بنفسك وشيلت `autoTitle` هيفضل زي ما كتبته.

## SEO والإطلاق (المرحلة 4)

- الـ `<head>` فيه Title وDescription وRobots وOpen Graph وTwitter Card، وصورة المعاينة `assets/img/og-image.jpg` (1200×630، بتتعمل بـ `node tools/make-og.js` من الاسم واللوجو).
- **Structured Data** (JSON-LD: WebSite + Person) وقائمة كل الأقسام والروابط جوه `<noscript>` بيتولّدوا من `data.js` بالأمر `node tools/seo.js`، وبيتشغّل تلقائي مع كل نشر على GitHub Pages.
- **الدومين**: حساب GitHub المختار `Abdelmalek-Studio` متسجّل في `tools/seo.config.json` (`githubUser`)، لكن المستودع لسه ماتعملش فمفيش رابط نهائي ومفيش حاجة بتتكتب بالتخمين. بعد إنشاء المستودع:
  - **المحفوظ دلوقتي** في `tools/seo.config.json`: `githubUser = Abdelmalek-Studio` و`plannedRepo = Abdelmalek-Studio.github.io` (الاسم المستهدف) و`repo` فاضي (لأن المستودع لسه ماتعملش). `tools/build.js` بيستخدم `plannedRepo` كافتراضي للبناء المحلي فبيطلع `dist/` بالرابط `https://abdelmalek-studio.github.io/` (الجذر)، وفي الـ workflow بياخد الاسم الحقيقي من `github.repository`. مجلد `site/` نفسه مفيهوش أي رابط مخترع. بعد ما تنشئ المستودع تقدر اختياريًا تثبّته: `node tools/seo.js --repo Abdelmalek-Studio.github.io` (أي اسم تاني بيدّي `…github.io/اسم-المستودع/`).
  - **أو من غير ما تعمل حاجة**: الـ workflow بيمرّر اسم المستودع الحقيقي (`--github owner/repo`) وقت كل نشر، فالـ canonical وog:url وصورة المعاينة وsitemap وسطر Sitemap بتتولّد صح في نسخة النشر.
  - دومين مخصص: `node tools/seo.js --domain https://دومينك` (وملف `CNAME` جوه `site/`) وله الأولوية. `--domain ""` بيشيله.
  - الأداة **آمنة للتكرار**: نفس الإعدادات = نفس الملفات بالظبط (sitemap من غير تاريخ تشغيل، وrobots.txt من غير تعليقات مكررة).
- الخط **Cairo** مستضاف محليًا (`assets/fonts/`، ترخيص OFL) بدل Google Fonts: أسرع، ومفيش طلبات لجهات خارجية للخط، ويشتغل أوفلاين. وزن الخطين العربي واللاتيني حوالي 65KB.
- فحص إمكانية الوصول (axe-core) على الديسكتوب والموبايل في الوضعين الغامق والفاتح: مفيش مشاكل غير العلامة الزخرفية `{ }` الباهتة في كروت البرومبت (`aria-hidden`، مقصودة).

## الاختبار

```
npm install && npx playwright install chromium
npm test                     # كل حاجة: فحص Syntax + كل ملفات الاختبار + إعادة التشغيل على نسخة الإنتاج dist/ + جدول (قديم/جديد، نجح/فشل)
npm run test:quick           # نفس الشيء من غير e2e (الأطول، حوالي 5 دقايق)
npm run build                # بيبني dist/ (اللي بيتنشر فعلًا) ويفحصه: node tools/build.js [--github owner/repo]
```

ملفات الاختبار (كل واحد بيشتغل لوحده: `node tests/<الملف>`):

| الملف | بيغطي |
|---|---|
| `e2e.js` (قديم) / `features.js` (قديم) | الاختبار الشامل للموقع واللوحة / الميزات + مسار GitHub Pages الفرعي |
| `migration.js` | تحويل tag → price/category: ثابت لو اتكرر، بلا فقدان، نفس القراءة في الموقع واللوحة |
| `routing.js` | الروابط المباشرة (#i=)، الفلاتر في الـ URL، Back/Refresh، مسار GitHub Pages الفرعي |
| `favorites.js` | المفضلة القديمة بعد إضافة المجموعات، التلويث، الحدود |
| `whatsnew.js` | «آخر الإضافات»: تواريخ، مراجع، عناصر محذوفة |
| `sections.js` | تصنيفات كل قسم + البحث الذكي المرتبط بالقسم (تايبوجرافي، رفع الجودة، المرادفات، النطاق، السعر لأدوات المواقع بس) |
| `search-filters.js` | البحث والفلاتر (قسم × سعر × تصنيف) ضد مرجع مستقل + تعارض tag القديم + الأداء + الموبايل |
| `admin.js` | استرجاع النسخ/الملفات القديمة، استيراد تالف، إضافة/تعديل/حذف وانعكاسها في الموقع |
| `images.js` | فحص الصور: موجودة/مفقودة/بطيئة/مهلة/تالفة |
| `security.js` | XSS في مدخلات اللوحة والاستيراد والموقع والـ hash والـ localStorage، روابط خطيرة، تلويث prototype |
| `magnific.js` | تصنيف Magnific (محتوى مجاني ومدفوع – أدوات AI مدفوعة): البيانات والبحث والفلاتر والكارت واللوحة |
| `design.js` | مرحلة التصميم: عرض الشاشة كلها، شريط التنقل العلوي + إلغاء الصوت، لون لكل قسم، الضغط على قسم يظهر محتواه فورًا، الموبايل، الفاتح/الغامق، وaxe (WCAG AA) |
| `production.js` | محتوى dist/ (مفيش admin/أسرار)، بناء ثابت، SEO على الجذر وبدون روابط مفترضة، العدّاد مقفول، تشغيل فعلي على الجذر |


الاختبار بيشغّل الموقع واللوحة من `file://` ويغطي: سلامة البيانات، البحث (بما فيه النطاقات والأداء)، نافذة الـ Prompt والنسخ، بدائل الصور، تحقق اللوحة (لينكات / صور / ألوان / معرّفات)، الاستيراد والتصدير والنسخ الاحتياطي من غير فقدان بيانات، رفض أي كود في الملفات المستوردة، و**8 مقاسات شاشة** (320 / 360 / 390 / 430 / 768 / 1024 / 1366 / 1920). لو الإنترنت مش متاح وعايز القياس بخط Cairo الحقيقي: `CAIRO_FONTS=/path/to/@fontsource/cairo/files node tests/e2e.js`.
